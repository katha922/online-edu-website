# 🎓 Online Education Website

A responsive online education platform built with React, Vite, and Firebase.

🔗 Live Demo:  
https://online-edu-website-7ab82.web.app

## 🚀 Features
- Course & service listing
- Enrollment & contact forms
- Admin dashboard
- Firebase Authentication
- Firestore integration

## 🛠 Tech Stack
React • Vite • React Router • Firebase • Firestore • Firebase Hosting
